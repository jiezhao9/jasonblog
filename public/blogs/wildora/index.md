欢迎来到小旷野，
在这里记录你的梦想与人生清单。
	
一起守护珍贵的心愿与梦想，
一起追风，一起抵达。
	
用安静、自由、随性又积极的方式，
把日子过成你想要的旷野。
	
# 🌳 【梦想之树】
人生漫漫，可以找一棵树陪伴。
你的每一次努力，小愿望的实现，都将化作能量，让你的梦想之树慢慢长大。
你会看见，坚持真的会生根发芽。
	
# 📒 【人生清单】
用清单安放你的生活、旅行、情感、阅读、影音、运动、财富，以及所有奇奇怪怪的小念想。
用一个清单或一个事项来跟踪，清晰又轻盈。
	
# 📷【轻松笔记】
可以针对你的清单、你的事项，随性记录。
回看来时路，真诚记录的喜怒哀乐，都是你认真活过的证据。
	
# 🎆 【丰盈人生】
世界很大，我们都想去看看。
看看别人的人生清单，或许眼前一亮，然后改造成自己独一无二的人生清单，勇敢追梦。
这里既是你的心愿自留地，也可以是灵感共鸣的小站。
	

人生不是轨道，而是旷野。
在小旷野，一起记录属于你的梦想之旅。
